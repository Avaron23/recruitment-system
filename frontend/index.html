Система подбора персонала

О системе

Интеллектуальная система автоматического подбора персонала. Использует алгоритм многокритериального анализа для сопоставления кандидатов с вакансиями и расчета процента совпадения на основе опыта, навыков, образования, зарплаты и готовности к переезду.

Структура системы

Backend (FastAPI + PostgreSQL)

  • Управление данными кандидатов и вакансий
  • Расчет матчей по алгоритму
  • Управление настройками весов

Frontend (HTML5 + CSS3 + JavaScript)

  • Управление кандидатами и вакансиями
  • Просмотр матчей и ранжирования
  • Конфигурация параметров системы

Как работает алгоритм

Система рассчитывает процент совпадения кандидата (0-100%) по следующим компонентам:

Опыт: Сравнивает количество лет опыта кандидата с требуемым опытом в вакансии
Обязательные навыки: Проверяет наличие всех требуемых навыков
Желательные навыки: Рассчитывает процент совпадения с желательными навыками
Образование: Соответствие требуемому уровню образования
Зарплата: Совместимость желаемой зарплаты с предложением
Переезд: Готовность кандидата к переезду при необходимости

Настройка системы

Каждому критерию присвоен вес (коэффициент), который определяет его влияние на итоговый процент совпадения. Все веса хранятся на сервере и могут быть изменены в разделе Настройки.

Также в настройках можно установить минимальный порог совпадения, начиная с которого кандидаты будут отображаться в ранжировании.

Основные разделы

  • Кандидаты — добавление и управление кандидатами
  • Вакансии — создание и управление открытыми позициями
  • Совпадения — просмотр всех созданных матчей
  • Ранжирование — ранжированный список кандидатов для выбранной вакансии
  • Настройки — конфигурация весов и порога системы

Возможности

  • • Автоматический расчет совпадения между кандидатом и вакансией
  • • Визуализация результатов с цветовыми индикаторами
  • • Отображение совпадённых навыков
  • • Гибкая конфигурация критериев оценки
  • • Ранжирование кандидатов по релевантности
  • • Установка обязательных критериев для вакансий
