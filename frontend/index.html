Главное Кандидаты Вакансии Совпадения

Экспертная система подбора персонала

Описание проекта

Это дипломный проект который заключается в создании экспертной системы по подбору персонала. Проект разбит на две части, backend и frontend. Backend - написан на python с использованием фреймворка FastAPI и с подключением к базе данных PostgreSQL. В базе данных три таблицы, с кандидатами, вакансиями и совпадениями. Первая таблица хранит в себе всех кандидатов, вторая хранит в себе вакансии, третья же совпадения, третья создаётся при помощи алгоритма, написанного на python, с помощью API с ними можно взаимодействовать.
