Главное Кандидаты Вакансии Совпадения

🎯 Экспертная система подбора персонала

📋 Описание проекта

Это дипломный проект, представляющий собой интеллектуальную систему автоматического подбора персонала. Система использует алгоритм скорирования для сопоставления кандидатов с вакансиями на основе нескольких критериев, что позволяет значительно сократить время на поиск оптимальных кандидатов.

🛠️ Архитектура

Backend

  • Фреймворк: FastAPI (Python)
  • БД: PostgreSQL
  • API: RESTful endpoints

Frontend

  • Язык: HTML5, CSS3, JavaScript
  • Архитектура: Single Page Application
  • Стиль: Адаптивный дизайн

📊 Основные компоненты

👥 Управление кандидатами

Добавление, просмотр и удаление кандидатов. Хранение информации о опыте, образовании, навыках, желаемой зарплате и готовности к переезду.

💼 Управление вакансиями

Создание и ведение списка открытых позиций с указанием требуемых навыков, опыта, образования, предлагаемой зарплаты и условий переезда.

🎯 Система матчинга

Автоматический расчет совпадения между кандидатом и вакансией с использованием алгоритма многокритериального анализа.

⚡ Алгоритм скорирования

Каждый матч рассчитывается по следующим критериям (общий счет 0-100%):

30% Опыт работы: Сравнение опыта кандидата с требуемым опытом вакансии
35% Совпадение навыков: Процент совпадения требуемых и имеющихся навыков
15% Образование: Соответствие требуемому уровню образования (профильное/непрофильное/среднее)
10% Зарплата: Совместимость желаемой зарплаты кандидата и предложения компании
10% Готовность к переезду: Соответствие требованиям по релокации

🚀 Функциональность

  • ✅ Интуитивный интерфейс для управления кандидатами и вакансиями
  • ✅ Реал-тайм расчет процента совпадения между кандидатом и вакансией
  • ✅ Визуализация результатов с помощью прогрессбаров и цветовых индикаторов
  • ✅ Отображение совпадённых навыков для каждого матча
  • ✅ Удаление и управление матчами
  • ✅ Полная синхронизация между frontend и backend через REST API

💡 Преимущества системы

Автоматизация: Система автоматически анализирует большой объем данных, что экономит время HR-специалистов.

Объективность: Алгоритм работает по четко определенным критериям, исключая субъективные факторы.

Точность: Комплексный анализ по пяти параметрам обеспечивает более точное определение подходящих кандидатов.
